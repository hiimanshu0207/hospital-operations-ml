# Data Directory

This directory stores **synthetic, non-identifying** hospital datasets used
for development and model training.

All data is generated programmatically — no real patient information is used.

## Contents (populated starting Day 3)

| File | Description |
|------|-------------|
| `patients.csv` | Synthetic patient arrivals |
| `departments.csv` | Hospital department metadata |
| `beds.csv` | Bed inventory and occupancy |
