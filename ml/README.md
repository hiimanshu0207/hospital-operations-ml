# ML Module

This directory will contain all machine-learning code:

- `data_generator.py` — Synthetic hospital data generation
- `preprocessing.py` — Feature engineering and data cleaning
- `models/` — Trained model artifacts (`.pkl`, `.joblib`)
- `train.py` — Model training pipelines
- `predict.py` — Inference utilities

Work begins on **Day 3** of the project plan.
